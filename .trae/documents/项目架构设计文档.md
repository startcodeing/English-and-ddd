# 英语学习平台项目架构设计文档

## 1. 项目概述

### 1.1 项目简介
英语学习平台是一个基于领域驱动设计（DDD）的现代化英语学习应用，提供词汇管理、内容学习、练习测试和学习活动跟踪等核心功能。项目采用前后端分离架构，后端使用Spring Boot + DDD架构，前端使用React技术栈。

### 1.2 技术栈
- **后端框架**: Spring Boot 2.7.14
- **开发语言**: Java 17
- **数据库**: H2 Database（开发环境）
- **ORM框架**: MyBatis + JPA
- **事件框架**: Axon Framework 4.7.4
- **前端框架**: React 18 + TypeScript
- **UI组件库**: Ant Design
- **构建工具**: Maven（后端）+ Vite（前端）

## 2. 整体架构设计

### 2.1 架构风格
项目采用**六边形架构（Hexagonal Architecture）**结合**领域驱动设计（DDD）**的架构风格：

```
┌─────────────────────────────────────────────────────────┐
│                    Interfaces Layer                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ REST APIs   │  │ Web UI      │  │ Events      │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
├─────────────────────────────────────────────────────────┤
│                   Application Layer                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ App Service │  │ DTO Mapping │  │ Validation  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
├─────────────────────────────────────────────────────────┤
│                     Domain Layer                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ Entities    │  │ Value Obj   │  │ Domain Svc  │     │
│  │ Aggregates  │  │ Events      │  │ Repository  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
├─────────────────────────────────────────────────────────┤
│                Infrastructure Layer                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ Database    │  │ File System │  │ Event Bus   │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
```

## 4. 技术架构详解

### 4.1 分层架构

#### 4.1.1 接口层（Interfaces Layer）
- **职责**: 处理HTTP请求，数据转换，异常处理
- **技术**: Spring MVC, REST API
- **组件**: Controller, ExceptionHandler, Validator

```java
@RestController
@RequestMapping("/api/v1/vocabulary/word")
public class WordController {
    private final WordApplicationService wordService;
    
    @PostMapping
    public Result<WordDTO> createWord(@Valid @RequestBody WordDTO dto) {
        return Result.success(wordService.createWord(dto));
    }
}
```

#### 4.1.2 应用层（Application Layer）
- **职责**: 编排业务流程，事务管理，DTO转换
- **技术**: Spring Service, MapStruct
- **组件**: ApplicationService, DTO, Mapper

```java
@Service
@Transactional
public class WordApplicationServiceImpl implements WordApplicationService {
    private final WordRepository wordRepository;
    private final WordEventPublisher eventPublisher;
    
    public WordDTO createWord(WordDTO dto) {
        Word word = wordMapper.toEntity(dto);
        word.createWord(word);
        Word savedWord = wordRepository.save(word);
        
        // 发布领域事件
        eventPublisher.publishWordCreatedEvent(new WordCreatedEvent(savedWord));
        
        return wordMapper.toDTO(savedWord);
    }
}
```

#### 4.1.3 领域层（Domain Layer）
- **职责**: 核心业务逻辑，领域规则，领域事件
- **技术**: 纯Java对象，无框架依赖
- **组件**: Entity, ValueObject, DomainService, Repository接口

#### 4.1.4 基础设施层（Infrastructure Layer）
- **职责**: 数据持久化，外部服务集成，技术实现
- **技术**: MyBatis, JPA, Axon Framework
- **组件**: RepositoryImpl, Mapper, EventHandler

### 4.2 数据持久化架构

#### 4.2.1 数据库设计
- **主数据库**: H2 Database（开发环境）
- **ORM策略**: MyBatis（复杂查询）+ JPA（简单CRUD）
- **事务管理**: Spring Transaction

#### 4.2.2 Repository模式
```java
// 领域层Repository接口
public interface WordRepository {
    Optional<Word> findById(String id);
    Word save(Word word);
    void deleteById(String id);
    List<Word> findBySpelling(String spelling);
}

// 基础设施层实现
@Repository
public class WordRepositoryImpl implements WordRepository {
    private final WordPoMapper mapper;
    private final WordPoConverter converter;
    
    @Override
    public Word save(Word word) {
        WordPo po = converter.toPo(word);
        mapper.save(po);
        return converter.toEntity(po);
    }
}
```

## 12. 总结

本英语学习平台采用现代化的技术架构和设计模式，具有以下特点：

1. **领域驱动**: 基于DDD的领域模型设计，业务逻辑清晰
2. **分层架构**: 清晰的分层结构，职责分离
3. **事件驱动**: 基于事件的松耦合架构
4. **前后分离**: React + Spring Boot的现代化技术栈
5. **可扩展性**: 模块化设计，支持水平和垂直扩展
6. **可维护性**: 标准化的代码结构和开发规范

该架构设计为项目的长期发展和维护提供了坚实的技术基础。
