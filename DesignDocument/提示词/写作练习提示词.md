### 2.Trae提示词
```html
我需要实现现有系统中的“写作练习”模块，该模块属于练习模块的子模块，依赖“写作主题管理”模块。

---

💡 功能概述：

- 管理写作练习，包括列表、查询、新建、编辑、删除等功能。

- 写作练习需关联一个“写作主题”（从写作主题模块拉取）。

- 包含倒计时功能：开始写作后倒计时，时间到自动提交内容。

---

🧱 技术选型：

- 后端：Spring Boot + JPA

- 前端：React + Ant Design

- 前后端交互方式：RESTful API

- 后端结构：

- domain-practice：领域层

- application-practice：应用服务层

- interfaces-practice：接口控制层

- infrastructure-db：数据访问实现

- infrastructure-event：事件发布实现

---

1. 该模块的数据库结构（表名：`writing_practice`）：

- id: Long

- topic_id: Long（关联写作主题）

- status: String（draft 草稿 / published 提交）

- content:String (写作内容，longtext)

- score: Long

- create_time: datetime（JPA @CreatedDate 自动填充）

- update_time: datetime（JPA @LastModifiedDate 自动更新）

---

2. 前端：

- 页面的原型请参考 writingModule.html 实现

- 使用 React 编写页面，组件库可以参考当前已有功能的实现

- 提供：

- 列表页（含分页、搜索、编辑、删除）

- 表单页（用于新增和编辑）

- 与后端进行完整联调，调用实际接口

- 写作练习的创建页面有一个倒计时，倒计时结束时，应该自动提交当前写作练习

- 创建新写作练习页面的写作主题下拉列表使用“写作主题管理”的列表内容，下拉框的展示内容为“写作主题描述-难度级别”

- 页面的交互方式，布局以及样式和当前已有模块保持一致

3. 其它说明：

- create_time 和 update_time 后端自动填充

- 联调后确保完整可用（前端能发起请求并接收到正确响应）

```
