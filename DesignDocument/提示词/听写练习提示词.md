### Trae提示词
```markdown

我需要实现现有系统中的“听写练习”模块，该模块属于练习模块的子模块，依赖“听力资料管理”模块。

---

💡 功能概述：

- 管理听写练习，包括列表、查询、新建、编辑、删除等功能。

- 听写练习需关联一个“听力资料”（从听力资料管理模块获取）。

---

🧱 技术选型：

- 后端：Spring Boot + JPA

- 前端：React + Ant Design

- 前后端交互方式：RESTful API

- 后端结构：

- domain-practice：领域层

- application-practice：应用服务层

- interfaces-practice：接口控制层

- infrastructure-db：数据访问实现

- infrastructure-event：事件发布实现

---

1. 该模块的数据库结构（表名：`writing_practice`）：

- id: Long

- listen_material_id: Long（关联听力资料）

- status: String（draft 草稿 / published 提交）

- content:String (听写内容内容，longtext)

- score: Long

- create_time: datetime（JPA @CreatedDate 自动填充）

- update_time: datetime（JPA @LastModifiedDate 自动更新）

---

2. 前端：

- 听写练习创建页面，需要先选择一个听力资料，选择后，弹出播放的按钮和进度条，下面提供“听写”输入框，支持富文本输入，用户将听到的内容输入到输入框，右下角显示取消和保存按钮

- 使用 React 编写页面，组件库可以参考当前已有功能的实现

- 提供：

- 列表页（含分页、搜索、编辑、删除）

- 表单页（用于新增和编辑）

- 与后端进行完整联调，调用实际接口

- 创建听写练习页面的听力资料下拉列表使用“听写资料管理”的列表内容，下拉框的展示内容为“听力资料名称-难度级别”

- 页面的交互方式，布局以及样式和当前已有模块保持一致

3. 其它说明：

- create_time 和 update_time 后端自动填充

- 联调后确保完整可用（前端能发起请求并接收到正确响应）

```
